# U32 排版操作加载反馈

2026-10-25，限定范围已验收。固定双代理复用，保留U31及其它未提交修改，不发布、不改版本或用户数据。

## 需求与实现边界

横竖方向切换和自动排版在确认后立即提供可见反馈；加载先绘制，再进行捕获/保存/请求/应用。保留现有图形为背景，以轻遮罩、转圈和真实操作文案过渡，直到新XML完成应用和绘制才恢复交互。没有百分比、虚假成功、强制最短加载时间或编辑器重挂。

排版操作状态与切图、普通保存分开。防止重复操作，取消确认不进入加载；请求失败、保存失败、应用失败也要清理遮罩并保留既有错误恢复路径。深浅主题及减少动态偏好可用。

## 分工

- 原dev_application：NativeStudio实际生命周期和重试/确认边界。
- 原dev_engine：DrawioViewport操作层、样式和隔离延迟/失败探针。
- PM：审查差异及真实页面/构建验收。

## 验收结果

### PM 实页独立验收

在5297隔离CloudStudio中，用真实draw.io流程图执行；仅fixture对排版请求增加1500ms延迟便于观察，生产代码无人工延迟。证据在 `output/playwright/u32-review/`。

- 点击方向先出现原确认窗口，取消不触发操作遮罩。
- 确认横向排版后，立即看到“正在切换为横向排版…”和实际旋转的spinner；CSS transform实读为旋转矩阵。原图仍显示在半透明背景下，画布slot inert、aria-busy=true，按钮不可重复提交。
- 完成后横向选中态为true，遮罩消失，画布和工具恢复。
- 深色模式实际自动排版显示“正在自动排版…”；没有重挂工作台或白/黑大页面闪过，完成后恢复。
- fixture预置下一请求503，纵向切换仍先展示加载；失败后遮罩清除，原横向图保留，明确显示可重试提示。点击“重试同一排版”再次展示加载，成功后纵向选中态为true，原生iframe数量始终2。
- 恢复后实际双击节点并改为“U32编辑验证”，自动保存成功；普通编辑/自动保存不触发排版遮罩。
- 减少动态偏好由媒体规则禁用spinner旋转和淡变；此项为源码审查，未将媒体偏好仿真写成实测通过。
