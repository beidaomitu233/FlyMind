## 参考观察

已通过真实浏览器查看 https://c.hui7.fun/#stage：4张大卡2×2，序号、角落箭头、标题与一句说明；整卡选择有明显背景反馈，旁边内容随选项改变。采用层次和整卡交互，配色继续使用FlyMind主题。

## 验收口径

1. 首页整卡可点击且可键盘操作；hover抬起阴影，减少动态偏好生效；无嵌套小按钮。
2. Agent面板只有统一安装路径和复制消息，不出现用户要求删除的高级说明。OAuth仍走客户端本人授权，复制/关闭不伪造连接。
3. 四步大卡保持创建、连接、交替修改及团队入口；每步可跳过，关闭可重进，实际进度含义不改变。
4. 计时从点击图形到正确图形可编辑；冷浏览器首入、热打开和连续切换分别列出。记录节点/边数量及测量环境，不用静态预览代替可编辑状态。
5. 不改真实用户图形或密码；隔离数据和测量输出放output。

## 当前发现

- 每次prepare创建新iframe，重复初始化draw.io。
- 原vendor资源统一no-cache，热打开仍逐项校验；历史线上app.min与extensions下载分别出现约7秒/17秒。
- 默认启动数学组件，无公式图也负担额外初始化。

## 最终性能与限制

从列表点击到正确图形XML、原生load和输入就绪，并实际打开节点编辑验证。详细口径及复现见[引擎测量](u31-drawing-opening.md)，最后一轮 `output/playwright/u31-opening/report-full.json`：

| 图形 | 规模 | 当前XML与输入就绪 | 含实际编辑验证 |
|---|---|---|---|
| 小流程 | 8节点 / 9边 | 243ms | 325ms |
| 完整技术架构 | 24节点 / 9组 / 14边 | 330ms | 412ms |
| PBS泳道 | 23节点 / 26边 | 376ms | 448ms |
| 合成宽树压力图 | 240节点 / 239边 | 602ms | 921ms（含实际放大及编辑核对） |

这些是本机隔离环境、首页预热后的单次实测，不是线上P95。第一轮未预热冷启动约2.36秒，首次下载成本不能消失；从刚操作的大图退出再进入小图，本次为1516ms，含原图捕获/保存，仍无法承诺所有切入小图都小于1秒。极端240节点纵链在1%整图缩放下虽真实就绪554ms，但难以直接定位文字，作为长图视口边界保留。**不能把有限样本达标说成任意复杂度、任意网络都保证2秒。**
