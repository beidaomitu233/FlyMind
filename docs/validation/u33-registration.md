## 交付行为

- 原登录页提供“没有账号？注册 / 已有账号？登录”。仅手机号、自设密码两项，支持显隐、忙碌防重复和错误提示；切换清理密码/错误，保留非敏感上下文。
- 手机号为11位大陆格式；前台密码至少6字符、非全空白且不超过72 UTF-8字节，允许 `123456`，不要求复杂组合。未接入短信，不宣称手机号已验证。
- 注册成功自动登录，生成公共6位字母数字用户 ID、个人空间及 owner 成员关系；沿原首用引导进入绘图。原 OAuth 请求继续到同意页面，复制或注册不等于已经完成 MCP 授权。
- 新前台账号拥有独立凭据，无后台角色；`sys_user.password` 使用不同的随机不可知密码。已有、禁用、删除或后台保留手机号不被注册接管；同应用租户手机号冲突返回409 `ACCOUNT_EXISTS`。
- Java 同事务创建身份、凭据、空间、成员、公共 ID 与会话；现有唯一索引阻断重复，无新 SQL 迁移。并发冲突后使用 `FOR UPDATE` 当前读，避免 MySQL REPEATABLE READ 的旧快照误判。
- BFF 强制同源 Origin，即使带 Bearer 也不能绕过；注册 JSON 上限1KiB，严格只接收 phone/password。沿登录写入 HttpOnly/SameSite Cookie，不向浏览器响应暴露令牌；失败不清除已有会话。
