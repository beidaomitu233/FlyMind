## 自动部署边界

`CLOUD_AUTO_PRODUCTION=false`，没有假造自动部署成功。现有 SSH 只有上传已知包与固定晋级命令，不给通用 shell；应用和 admin 随 current 晋级，Java/网关单独受控更新。仅此部署制品的短期签名下载地址转交服务器被自动审批拒绝，已向用户请求明确授权；未传送该地址，也未传送 GitHub 账户 token。

已编写默认关闭的受限制品HTTPS通道和失败job重跑身份修复：CI固定官方API取artifact专用短时URL，服务器固定root配置主机/公网IP/TLS、不跟跳、不传账号token，校外层ZIP及内层tar摘要后走原调度器。PM独立Node8/8、Python本地假源4/4通过。实际服务器helper安装、真实短时URL和Linux原子发布未验，开关未启用；详见[部署说明](../../deploy/cloud/README.md)。
