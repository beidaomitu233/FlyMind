# 可选的 compact-1g 内存配置

默认配置不变：浏览器与 SVG 工作进程准入要求至少 512 MiB，SVG 子进程 V8 堆上限 256 MiB、RSS 上限 384 MiB。只有服务环境变量明确设置 `FLYMIND_MEMORY_PROFILE=compact-1g` 才启用紧凑配置：浏览器与 SVG 准入 384 MiB，SVG 子进程 V8 堆上限 160 MiB、RSS 上限 256 MiB。未知值使用默认配置。compile 等非 SVG 工作的原有 384 MiB 准入、256 MiB RSS 和 256 MiB 堆上限不变；运行中 128 MiB 紧急余量和既有队列、取消、关闭与浏览器 sandbox 不变。

该选项不是操作系统内存限额，必须由管理员配合已验证覆盖服务及所有后代的 `flymind.slice` 1 GiB 硬边界和不重叠的发布维护流程使用。配套 `MemoryHigh=1000M` 高于 1024−128 MiB 的配置边界，但内核和应用使用不同的采样及内存口径，不保证应用取消一定先于内核节流。安装配置或启动进程本身不能证明该边界有效，也不能保证任意图形在此配置下成功。堆/RSS 较小可能令复杂 SVG 工作失败；准入较低可能触发运行时压力取消或 cgroup OOM。配置前后应在等价的受限环境验证真实浏览器 sandbox、字体、PNG/SVG 与编辑保存，并记录 cgroup 峰值及 OOM 事件；失败应保持明确错误和原任务重试语义，不应放宽保护或改用其他渲染路径冒充成功。
