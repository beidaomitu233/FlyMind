# 画布对象与选择片段

适用于 0.5.0。普通 AI 绘图继续只编写 content；本文件描述人工画布操作及独立 rendering 配置。

## 业务归属与画布组合

| 数据 | 含义 |
|---|---|
| content.lanes / phases / groups | 角色泳道、业务阶段、架构分层；节点通过 laneId/phaseId/groupId 关联 |
| rendering.objects.groups | 画布组合；节点共同选择、移动及缩放，不改变业务归属 |
| rendering.objects.locked | 锁定节点 ID 列表；固定当前几何及外观，修改前解锁 |
| rendering.objects.order | 节点从底到顶的顺序；不改变 content.nodes 的业务顺序 |

```json
{
  "groups": {"canvas_group_1": ["request", "review"]},
  "locked": ["request", "review"],
  "order": ["done", "request", "review"]
}
```

这是 objects 子配置。使用 MCP configure_rendering 时先读取完整配置并保留其他字段。节点最多属于一个画布组合，组合不嵌套；删除后不足两个节点的组合自动移除，失效锁定/图层 ID 自动清理。未列入 order 的节点按内容数组顺序先绘制，显式列出的节点在其上方绘制。节点顺序同步至 SVG、PNG 和 draw.io；SVG/PNG 中容器和连线在节点下方。

锁定会记录当前位置、尺寸和有效节点样式。网页不显示编辑手柄，属性字段禁用；框选和全选跳过锁定节点，仍可单击或右键选中并解锁、复制。锁定组合会锁定其成员。网页保存与 MCP 内容修改共享约束；增添其他节点不改变已固定的几何。连线是独立对象，可继续修改。解锁保留当前外观；主动自动布局才能清除该节点手动排布。

锁定是编辑行为，不是权限或安全边界。导出的工作区 JSON 保留对象配置；纯内容 JSON 不保留。draw.io 交换文件保留视觉与堆叠，不承诺迁移 FlyMind 的组合/锁定行为。

## 复制、剪切与粘贴

- Ctrl/Cmd+C 复制选择，X 先复制再删除，V 粘贴至视口中心；连续粘贴错开 24 个画布单位。右键粘贴以点击处作为片段中心，靠近图纸左/上边界时限制在边界内。
- 思维导图复制主题时包含其子树；其他图形复制所选节点及内部连接。外部连接不复制。
- 新节点、连线和画布组合生成新 ID。副本解除锁定，保留节点外观、尺寸和内部连线样式。
- 五类图形互相粘贴：节点类型适配目标；泳道/阶段/分层按同图 ID 或名称匹配，缺失时创建。无对应业务容器的来源使用目标选中节点或首个容器的归属。
- 粘贴到思维导图时，片段根附到所选主题或现有根；内部 parentId 保留。普通图关系以额外 edges 保留，包括回流；思维导图粘到其他图时，父子关系转为 edges。
- 每次粘贴、剪切、组合、锁定、堆叠或完成缩放是一次历史操作，可撤销/重做并自动保存。校验失败不保存；剪切无法删除全部节点或锁定后代时保留原节点。

系统剪贴板使用 JSON 文本，片段格式为：

```text
{format:"flymind.selection",version:1,sourceId,kind,
 content:{nodes,edges,lanes,phases,groups},rendering:{...}}
```

content 保持纯语义；rendering 携带有效节点几何、样式、卡片和内部线路覆盖。导入校验引用、层次、几何和 2 MB 大小限制。它是选择片段，不能直接作为 create_diagram 的 content 参数。

浏览器拒绝系统剪贴板访问时，右键操作使用本机 localStorage 缓存。若可读的系统剪贴板包含普通文字或其他格式，则提示错误，不粘贴旧缓存。输入框使用原生文字复制/剪切/粘贴。系统剪贴板通常要求 localhost/HTTPS 及浏览器授权。

## 当前边界

图纸坐标仍从 16 起；真正的负坐标画布、视口外拖动自动平移和容器缩放属于 P3。画布组合只包含节点，不能包含独立连线或容器。多选缩放改变位置与尺寸，字号单独在渲染属性中调整；单节点手柄最小 72×40，多选缩放时每个节点至少 32×32。图层顺序操作针对节点，保留选择内部的相对顺序。
