# MCP 规范与画布编辑路线

研究日期：2026-10-12。每阶段完成实现、回归、文档，再进入下一阶段。状态按实际验收更新。

## 研究结论

MCP 协议规定工具、资源、输入输出及传输行为，没有强制 GitHub README 排版模板。采用成熟项目的说明结构，再用协议与测试约束实现。

## 必须保持的边界

- 内容层：节点内容、类型、业务关系及可选颜色。AI 普通绘图不填写坐标、尺寸、形状、布局行或线型。
- 渲染层：标准节点配置、自动布局、手动几何与样式覆盖。画布手势调用渲染配置。
- 跨泳道/分层拖动是业务归属变化，同时更新内容归属；普通移动、缩放不改节点文案和连接关系。
- MCP 与网页共享版本。AI 在人工编辑后重新读取，过期 revision 不可覆盖。
- 所有新交互以一次完成的手势作为一次历史操作；取消手势不保存。

## 分阶段执行

### P0：仓库与 MCP 契约规范化（已完成，0.4.0）

交付：README 安装/调用/交付/限制索引、贡献与安全说明、变更记录、CI 和问题模板；详细输入 schema、统一输出契约与注解、可读取的图形制品资源。

验收：真实 STDIO 客户端能发现工具字段和输出 schema；五类创建均返回 PNG、文件和编辑链接；资源能读取；语义/渲染混写被拒绝；并发冲突不覆盖数据。CI 执行构建与集成测试。

### P1：画布基础手势（已完成，0.4.0）

交付：单个和多个节点拖动的边缘/中心吸附与辅助线；单节点八方向缩放、Shift 保持比例；Shift 追加框选；视口变化保持相机，适应所选；统一手势取消与历史。

验收：不同缩放下吸附阈值一致、Alt 绕过；西北缩放保持对角固定；取消不写数据；一次拖动撤销一次；网页保存后 MCP 读取一致；打开属性面板不重置视角。

### P2：画布对象工作流（已完成，0.5.0）

顺序：选择片段格式 → Ctrl/Cmd+C/X/V 与粘贴定位 → 精简右键菜单 → 组合/取消组合与锁定 → 图层顺序和多选整体缩放。

先定义分组与泳道业务归属的区别；剪贴板处理新 ID、内部连线、跨图类型归属映射，禁止悬空引用。锁定对象不响应拖动或删除。每个操作都完成保存、撤销、再次读取闭环。

交付：选择片段分开保存内容与渲染；系统剪贴板、定位粘贴、精简右键菜单、画布组合/锁定、四种堆叠和多选八方向缩放已实现。组合不改变业务容器归属；内部手动折点与标签随整体几何变换。对象配置详见 [画布对象](CANVAS_OBJECTS.md)。

验收：33 项自动化测试通过，包括五类图形之间 25 组片段粘贴；真实 MCP 验证对象配置、锁定拒绝、解锁后增量修改与图片交付。浏览器通过 11 类检查：系统复制/粘贴、剪切撤销、组合移动、整体比例缩放、锁定与解锁撤销、堆叠、取消组合、定位粘贴、非图形剪贴板拦截、输入框原生操作、保存/重载/PNG。截图仅存本机 output/playwright/。后续按 P3 顺序推进。

### P3：自由画布与复杂图编辑（待执行）

顺序：支持负坐标的场景边界与导出裁切 → 视口外拖动自动平移 → 连线折点删除/正交编辑/连接预览 → 泳道和分层容器缩放 → 大图性能优化。

当前仍是可缩放平移的图纸工作区，尚未实现真正的无限画布。负坐标必须连同 SVG/PNG/draw.io 导出坐标系一起解决，不能只删除拖动限制。性能通过固定规模的图形与手势测量验证，不凭视觉判断。

### P4：AI 与人工编辑协作（待执行）

提供结构化修改摘要、冲突合并指引、选区定位/聚焦入口。验证 Codex 创建 → 用户大幅修改 → AI 重新读取 → 增量修改 → 回传图片和链接的完整链路。独立网页 API Key 生成功能是二期外围能力，不接入绘图核心。
